PENDAHULUAN
Tujuan Pembelajaran & Pola Pikir Kompetisi (Mindset)
PRINSIP UTAMA

💡 Filosofi Kompetisi

  • Bukan Tebak-Tebakan: CTF dirancang dengan alur logika terstruktur dan berbasis dasar ilmiah komputer.
  • Simulasi Nyata: Mengasah kemampuan audit keamanan web, analisis sandi, dan rekonstruksi barang bukti digital.
  • Kemandirian: Peserta ditantang untuk mencari solusi melalui riset dokumentasi dan alat investigasi.
METODOLOGI

🧠 Pola Pikir Investigasi

  • Pahami Arsitektur: Ketahui bagaimana protokol atau struktur file bekerja normal sebelum mencari kelemahannya.
  • Observasi Anomali: Perhatikan header tak lazim, ukuran berkas janggal, atau karakter teks yang berpola tertentu.
  • Formulasi Hipotesis: Susun hipotesis terukur (misal: 'Apakah ini format Base64?') lalu uji dengan alat yang tepat.
KETENTUAN RESMI

🚩 Format Jawaban Flag

  • Format Baku: Seluruh jawaban flag wajib diawali CTF{ dan diakhiri tanda kurung }.
  • Sensitif Huruf: Flag bersifat case-sensitive. Hindari spasi kosong di awal atau akhir string.
  • Proteksi Rate-Limit: Penyerahan flag diverifikasi otomatis oleh server dengan perlindungan anti brute-force.

DOMAIN 1: WEB EXPLOITATION
Fondasi Arsitektur Web & Vektor Analisis Klien-Server
KOMUNIKASI KLIEN - SERVER

📡 Permintaan & Respon HTTP

  • Siklus Request-Response: Browser mengirim permintaan HTTP dan server merespon dengan status code, header, dan payload.
  • Transmisi Header Kustom: Header respon memuat metadata penting. Pengembang terkadang meletakkan info di custom header (seperti X-...).
  • Komentar Kode Sumber: Inspeksi dokumen HTML/JS sering kali mengungkap catatan teknis atau petunjuk internal developer.
  • Perangkat: Gunakan Browser DevTools (F12) tab Elements dan tab Network.
LOGIKA OTORISASI & AKSES

🛡️ Kepercayaan Sisi Klien vs Sisi Server

  • Prinsip 'Never Trust Client': Sistem yang aman tidak mempercayai parameter otorisasi yang dikirim langsung dari browser tanpa validasi server.
  • Penyimpanan Sesi (Cookies): Jika status hak akses (seperti role admin) disimpan mentah di cookie, pengguna dapat memodifikasinya.
  • Perayap Web (Robots): Berkas robots.txt dibuat untuk memandu bot pencari, namun bersifat publik dan dapat dibaca siapa saja.
  • Integritas Kueri: Masukan form harus divalidasi agar tidak membelokkan logika kueri backend.

🔍 Topik 1: Inspeksi Transmisi & Header

  • Kompetensi Peserta: Memahami bagaimana pengembang menyembunyikan jalur sistem menggunakan berkas publik robots.txt.
  • Kata Kunci: Robots.txt, User-agent, Disallow Directive, Hidden Path, Crawler.
  • Arah Belajar: Pahami cara kerja web crawler, struktur direktif Disallow, dan penjelajahan endpoint tersembunyi.

🍪 Topik 3: Otorisasi & Manipulasi Cookie

  • Konsep yang Diuji: Pengelolaan status sesi pengguna (state management) menggunakan HTTP Cookies tanpa tanda tangan kriptografi.
  • Kompetensi Peserta: Mengenali variabel kontrol hak akses pada browser storage dan mengubah nilainya untuk menaikkan privilege.

💉 Topik 4: Logika Integritas Otentikasi (SQL)

  • Konsep yang Diuji: Evaluasi logika aljabar boolean pada formulir login yang terhubung ke database relasional.
  • Kompetensi Peserta: Menganalisis bagaimana karakter khusus memanipulasi klausa WHERE kueri sehingga selalu bernilai TRUE.
  • Kata Kunci: Boolean Tautology, SQL Logic Evaluation, Authentication Bypass, Quote Escape.
  • Arah Belajar: Pahami tabel kebenaran operator OR ('TRUE OR FALSE = TRUE'), karakter petik tunggal, dan manipulasi input.
DOMAIN 2: CRYPTOGRAPHY
Fondasi Kriptografi: Representasi Data vs Kriptosistem
FONDASI TEORITIS DATA

🔄 Encoding vs Enkripsi

  • Encoding (Penyandian Format): Mengubah format data agar aman ditransmisikan. TIDAK memerlukan kunci rahasia. Bersifat publik & reversibel sepenuhnya.
  • Contoh Encoding: Biner (Base-2), Heksadesimal (Base-16), Base64 (pemetaan 6-bit).
  • Enkripsi (Pengamanan Rahasia): Mengacak plaintext menjadi ciphertext dengan kunci rahasia tertentu. Hanya pemegang kunci yang dapat mendekripsinya.
  • Kriptosistem: Sandi klasik (substitusi/transposisi), operasi bitwise (XOR), dan polialfabetik.
METODE PEMECAHAN LOGIKA

🧩 Karakteristik Ciphertext & Analisis

  • Kenali Ciri Teks Sandi: Sandi pergeseran alfabet mempertahankan panjang kata. Hex hanya memuat 0-9 & A-F. Base64 sering diakhiri padding '='.
  • Sifat Simetri (Involutori): Operasi seperti ROT13 dan gerbang logika XOR memiliki proses dekripsi yang identik dengan enkripsinya.
  • Ruang Kunci Terbatas: Jika ukuran kunci pendek (1 byte = 256 kombinasi), pengujian menyeluruh (brute-force) sangat efektif.
  • Alat: CyberChef (GCHQ), script Python 3, dan dcode.fr.

Kisi-Kisi Topik 1 & 2: Sandi Pergeseran & Rantai Transformasi
TINGKAT DASAR | 100 POIN

🏛️ Topik 1: Sandi Pergeseran Alfabet Klasik

  • Konsep yang Diuji: Sandi substitusi monoalfabetik klasik berbasis aritmatika modulo 26 (Caesar Cipher / ROT13).
  • Kompetensi Peserta: Mengenali pola teks teracak yang mempertahankan tanda baca dan membalikkan pergeseran alfabet dengan interval tetap.
  • Kata Kunci: Caesar Shift, ROT13, Modulo 26, Monoalphabetic Substitution.
  • Arah Belajar: Pelajari rumus matematis C = (P + K) mod 26, simetri rotasi 13 huruf, dan resep ROT di CyberChef.
TINGKAT DASAR | 150 POIN

⛓️ Topik 2: Rantai Transformasi Multi-Format

  • Konsep yang Diuji: Pipelined / Layered Encoding, di mana pesan ditransformasikan melewati 3 format representasi data digital bertingkat.
  • Kompetensi Peserta: Mengidentifikasi pola biner 8-bit, mengonversinya ke heksadesimal, dan men-decode string Base64 secara terbalik.
  • Kata Kunci: Layered Encoding, Binary (Base-2), Hex (Base-16), Base64, Reverse Pipeline.
  • Arah Belajar: Pahami konversi deret biner ke teks ASCII, fungsi tabel hex, dan cara menyusun pipeline decoding di CyberChef.

Kisi-Kisi Topik 3 & 4: Aljabar XOR & Sandi Polialfabetik
TINGKAT MENENGAH | 200 POIN

⚡ Topik 3: Aljabar Bitwise XOR Ruang Kunci 8-Bit

  • Konsep yang Diuji: Operasi logika Exclusive OR (XOR / ^) bita biner dengan sifat matematis involutori (A ^ K ^ K = A).
  • Kompetensi Peserta: Memahami enkripsi XOR bita tunggal dan menguji seluruh ruang kunci 1-byte (0 hingga 255 variasi) untuk memulihkan pesan.
  • Kata Kunci: Bitwise XOR, Single-Byte Key Space (256), Brute Force Search, Involutory.
  • Arah Belajar: Pelajari tabel kebenaran gerbang XOR, operasi XOR byte-per-byte pada Python / CyberChef 'XOR Brute Force'.
TINGKAT MENENGAH | 250 POIN

📖 Topik 4: Sandi Polialfabetik Vigenère

  • Konsep yang Diuji: Sandi substitusi polialfabetik yang menggunakan kata kunci berulang (repeating keystream) untuk mengubah pergeseran tiap huruf.
  • Kompetensi Peserta: Mampu merekonstruksi pesan teks sandi dengan memetakan huruf sandi dan huruf kunci pada matriks Tabula Recta.
  • Kata Kunci: Vigenère Cipher, Tabula Recta Matrix, Repeating Keystream, Polyalphabetic.
  • Arah Belajar: Pahami cara kerja tabel pergeseran Vigenère, rumus dekripsi P = (C - K) mod 26, dan decoding menggunakan kata kunci.
DOMAIN 3: DIGITAL FORENSICS
Fondasi Forensik Digital: Struktur Berkas Biner & Transmisi
STRUKTUR DATA FISIK BERKAS

🔬 Anatomi Berkas Digital

  • Tanda Tangan Berkas (Magic Bytes): Sistem operasi mengenali tipe berkas dari byte penanda awal (offset 0x00), bukan sekadar ekstensi file.
  • Metadata Tersembunyi (EXIF): Berkas citra menyimpan metadata otomatis (perangkat, waktu, tag komentar pengembang) di luar kanvas visual.
  • Penanda Akhir Berkas (EOF): Format citra memiliki penanda penutup baku. Data yang disisipkan di balik batas EOF tidak akan dirender oleh image viewer biasa.
  • Integritas Bukti: Selalu bekerja menggunakan salinan berkas bukti (*working copy*) agar tidak merusak artefak asli.
ANALISIS TRAFIK JARINGAN

📡 Rekaman Paket Jaringan (PCAP)

  • Paket Transmisi Data: Komunikasi jaringan dipecah ke dalam bingkai paket yang mencatat IP sumber, tujuan, port, dan payload data.
  • Protokol Teks Polos (Clear-Text): Protokol seperti HTTP mentransmisikan data mentah tanpa enkripsi TLS. Isi percakapan dapat dibaca oleh analis.
  • Rekonstruksi Aliran Sesi (Streams): Paket yang terpecah dalam transmisi TCP dapat digabungkan kembali secara utuh untuk membaca request/file yang diunduh.
  • Alat: Hex Editor (HxD / HexEd.it), ExifTool, 7-Zip, dan Wireshark.

📷 Topik 1: Eksplorasi Metadata Berkas Citra

  • Konsep yang Diuji: Penyimpanan metadata Exchangeable Image File Format (EXIF) dan tag komentar teks di dalam berkas gambar.
  • Kompetensi Peserta: Mampu mengekstraksi atribut informasi non-visual yang tertanam di dalam dokumen citra digital.
  • Kata Kunci: EXIF Specification, UserComment / XPComment, File Properties Details, Strings.
  • Arah Belajar: Pelajari pembacaan tab Details di Properties berkas Windows, utilitas ExifTool, atau perintah terminal strings.
TINGKAT DASAR | 150 POIN

🩹 Topik 2: Integritas Struktur Biner (Magic Bytes)

  • Konsep yang Diuji: Kerusakan struktur tanda tangan berkas biner pada 8-byte pertama berkas gambar standar (format PNG).
  • Kompetensi Peserta: Mampu menggunakan Hex Editor untuk membaca byte mentah, mengidentifikasi kerusakan, dan menambal (patching) byte yang hilang.
  • Kata Kunci: Magic Bytes, File Signature, PNG Header (89 50 4E 47...), Hex Patching.
  • Arah Belajar: Pelajari spesifikasi magic bytes PNG, buka berkas di HxD atau hexed.it, perbaiki 8 byte pertama, lalu simpan file.

Kisi-Kisi Topik 3 & 4: Steganografi EOF & Analisis Trafik PCAP
TINGKAT MENENGAH | 200 POIN

📦 Topik 3: Steganografi Penanda Akhir Berkas (EOF)

  • Konsep yang Diuji: Penyembunyian kontainer berkas sekunder (seperti arsip ZIP) di balik penanda batas akhir berkas (EOF) citra JPEG.
  • Kompetensi Peserta: Mampu mendeteksi anomali struktur berkas di luar penanda EOF (FF D9) dan mengekstraksi arsip tersembunyi.
  • Kata Kunci: End of File (EOF), JPEG Marker (FF D9), Appended Steganography, File Carving.
  • Arah Belajar: Pelajari batas EOF JPEG, teknik membuka file gambar langsung menggunakan pengarsip (7-Zip / WinRAR), atau tool binwalk.
TINGKAT MENENGAH | 250 POIN

🦈 Topik 4: Analisis Lalu Lintas Jaringan (PCAP)

  • Konsep yang Diuji: Investigasi penyadapan paket jaringan mentah untuk menganalisis transmisi data protokol teks polos (HTTP).
  • Kompetensi Peserta: Mampu memfilter protokol jaringan tertentu di antara ribuan paket lalu lintas dan merekonstruksi aliran sesi komunikasi (TCP Stream Reassembly).
  • Kata Kunci: Packet Capture (PCAP), Display Filter 'http', Follow TCP Stream, Clear-Text Payload.
  • Arah Belajar: Pelajari penggunaan filter display Wireshark, fitur 'Follow -> TCP Stream', dan membaca transaksi request/response HTTP.
PERSIAPAN PESERTA
Matriks Kesiapan Perangkat Lunak (Tools Checklist)
KOMPONEN WEB

🌐 Perangkat Web

  • Browser DevTools: Chrome / Firefox / Edge (F12) untuk inspeksi DOM, network response header, dan cookie.
  • cURL / Postman: Pengujian request HTTP kustom dan verifikasi respons endpoint.
  • Proxy Opsional: Burp Suite Community Edition (opsional untuk analisis lalu lintas HTTP).
KOMPONEN KRIPTO

🔐 Perangkat Kriptografi

  • CyberChef (GCHQ): Tool serbaguna untuk ROT13, Base64, Hex decoding, dan XOR Brute Force.
  • Python 3: Scripting otomatis untuk kalkulasi bitwise, manipulasi string, dan modulo.
  • dcode.fr: Referensi online pengenal cipher klasik dan pemecah sandi substitusi/Vigenère.
KOMPONEN FORENSIK

🔍 Perangkat Forensik

  • HxD / HexEd.it: Editor heksadesimal untuk membaca biner mentah dan memperbaiki byte rusak.
  • 7-Zip / WinRAR: Pengarsip berkas untuk mendeteksi kontainer ZIP di balik steganografi gambar.
  • ExifTool / File Properties: Pembaca metadata EXIF dan komentar tak kasat mata.
  • Wireshark: Penganalisis paket jaringan dan rekonstruksi TCP stream.

TIPS INVESTIGASI EFEKTIF

💡 Menghindari Kesalahan Umum

  • Jangan Berspekulasi Liar: Semua tantangan memiliki dasar rasional. Jika buntu, baca ulang petunjuk dan deskripsi soal.

  • Gunakan Berkas Salinan: Saat memperbaiki byte file forensik, selalu buat berkas cadangan agar bukti asli tidak rusak permanen.
  • Berpikir Seperti Pengembang: Pikirkan bagaimana developer sistem membangun fitur tersebut, lalu temukan asumsi keliru mereka.
